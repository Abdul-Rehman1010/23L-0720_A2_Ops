Is this image AI-generated?

Upload a picture and VisionGuard will estimate whether it is a real photo or was made by an image generator.

How to read the result

  • The verdict is an estimate. The model looks at visual style, not at where the image came from, so it can be wrong in both directions.
  • We prefer not to accuse real photos. The decision threshold is set so that few genuine photos are wrongly called AI, which means some AI images pass as real.
  • Your image is not stored. It is analysed in memory; only the verdict, a fingerprint and the file name are kept in the history.
